    Welkom! Wat wil je installeren?

    Deze wizard installeert Pterodactyl op deze server. Je vult alles hier in, daarna doet de installer de rest en zie je de voortgang live.

    Waar moet het panel bereikbaar zijn?

    Kies het adres waarop jij en je klanten straks inloggen.

    ✓Zo werkt het: sslip.io stuurt automatisch door naar het IP van deze server. Let's Encrypt geeft daar een gratis certificaat op. Je hoeft niets in te stellen, alleen poort 80 en 443 moeten open staan.
    !Op een kaal IP-adres kan geen certificaat. Wil je SSL zonder domein? Kies dan het gratis sslip.io adres.
    Maak eerst een A-record aan dat naar wijst. Gebruik je Cloudflare? Zet de proxy (oranje wolk) dan uit tijdens de installatie.

    Node instellen

    Het panel staat op deze server, dus de installer kan de node zelf aanmaken en Wings meteen starten.

    Met een Application API key van je panel maakt de installer de node daar zelf aan en start Wings meteen.

    Maak hem aan in je panel onder Admin › Application API, met Read & Write op Nodes, Locations en Allocations.
    Bereik of lijst, bv. 25565-25600 of 27015,30120. Leeg = later zelf toevoegen.
    Kort, zonder spaties, bv. nl1 of ams.
    Geavanceerd: geheugen, schijf en poorten van Wings
    Leeg = automatisch (alles min 1 GB voor het systeem).
